PARTE A: COLORES POR NOMBRE

Se usan nombres de colores en ingles.

red
blue
green

PARTE B: COLORES RGB

Se usan valores de rojo, verde y azul del 0 al 255.

rgb(200,100,100)
rgb(100,200,100)
rgb(100,100,200)

PARTE C: COLORES HEXADECIMAL

Se usan codigos de 6 digitos con # al inicio.

#e74c3c
#2ecc71
#3498db

PARTE D: COLORES HSL

Se usan valores de Tono (H), Saturacion (S) y Luminosidad (L).

hsl(0,60%,60%)
hsl(120,60%,60%)
hsl(240,60%,60%)

PARTE E: COLORES CON OPACIDAD

Se usa rgba() o hsla() o la propiedad opacity.

rgba(200,100,100,1)
rgba(200,100,100,0.5)
rgba(200,100,100,0.2)
